# KAIDEEDER POS Android

Android WebView application for KAIDEEDER POS on SUNMI D2s Plus. It exposes the
restricted `window.AndroidPOS` JavaScript interface to trusted HTTPS POS pages and
prints receipts through SUNMI's internal printer service.

Use the repository-level `README_ANDROID_POS.md` for configuration, build, install,
security, and device-test instructions. Browser POS behavior remains available when
the native bridge is absent.
