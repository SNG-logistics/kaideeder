5. System Architecture
🌐 Frontend (Next.js 14)
📁 src/app/(dashboard)/ — Admin UI
📁 src/app/d/[tenant]/ — Delivery Checkout
📁 src/app/m/[tenant]/ — QR Dine-in Menu
📁 src/app/rider/ — Rider Dashboard
📁 src/app/login/ — Login Page
🎨 Vanilla CSS + CSS Variables
🗄️ Backend API (Next.js Route Handlers)
/api/auth/ — Login / Me / Logout
/api/pos/ — POS Orders, Delivery
/api/public/ — Menu, Delivery Order (no auth)
/api/settings/ — Store, Users, QR Banking
/api/inventory/ — Products, Stock, GR
/api/tenant/ — Tenant settings, QR
🔒 Security (RBAC)
JWT Token (httpOnly Cookie, 30d)
withAuth() middleware — ทุก API
Multi-tenant isolation — tenantId
Role-permission mapping ที่ permissions.ts
Rider transition guard (state machine)
Owner bypass — ผ่านทุก guard เสมอ
🗃️ Database (MySQL + Prisma)
Tenant, User, Product, Category
MenuItem, Order, OrderItem
DeliveryInfo, CustomerProfile
Inventory, GoodsReceipt, Transfer
StockCount, Recipe, BOM
ConsumeLog, WasteLog, Movement
☁️ Hosting (Hostinger)
Domain: kaideeder.com
Node.js runtime + PM2 process manager
MySQL 8.x (127.0.0.1:3306)
Nginx reverse proxy + SSL
📂 .next/standalone — production build
npm run deploy — build + db:push
